Security, deliberately layered

Your credentials
stay yours.

Local vaults use Argon2id key derivation and AES-256-GCM authenticated encryption. Cloud records are encrypted on your device; credentials reach the managed gateway over TLS only while an SSH connection is being established.

01Local vaultEncrypted at rest with owner-only file permissions.

02Verified hostsSSH host keys are checked before trust is established.

03No secret loggingCloud credentials are not written to the service database or logs.
